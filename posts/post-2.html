Notes on Measuring Things at Scale

Placeholder excerpt: every large measurement study starts the same way — with a script that should take an afternoon and ends up running for three months. This post is a stand-in for your own write-up.

Lesson one: everything retries

Networks are unreliable, so measurement code must assume every request can fail, hang, or return something unexpected:

  • Wrap every probe with a timeout
  • Log raw responses, not just parsed results
  • Make every run resumable

Lesson two: look at the data by hand

The single most useful habit: open the raw output and read a few hundred lines before writing any aggregation code. Every surprising bug in our pipeline was visible in the raw data first.
