Deployment beats features

A tool that is running somewhere imperfectly beats a perfect tool that is still on a laptop. Ship the smallest useful thing first:

  1. One clear entry point (a URL, a CLI, a dataset)
  2. Documentation that fits on one screen
  3. A way for users to tell you it broke
The best instrumentation is the kind someone else maintains for you.
